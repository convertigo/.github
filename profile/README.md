# Convertigo

## Open-source enterprise Low-Code & No-Code platform

Convertigo is an AI-driven, self hostable full-stack platform for building, integrating and deploying enterprise web, mobile and desktop applications.
[![Docker Pulls](https://img.shields.io/docker/pulls/convertigo?logo=docker&label=Docker%20pulls)](https://hub.docker.com/_/convertigo)

It combines:

- **Low Code Studio** for professional developers and IT teams
- **No Code Studio** for business users and governed citizen developers
- **Convertigo Server** for APIs, workflows, integrations, security and offline data synchronization
- **AI and MCP capabilities** for application development with coding agents and LLM-powered workflows

Convertigo supports pixel-perfect user interfaces, complex business logic, mobile offline applications, legacy-system integration and flexible deployment across managed cloud, private cloud and on-premises infrastructure.

## Open source and licensing

Convertigo is available under a dual-license model:

- **GNU AGPL v3**
- **Commercial license**

Both licenses use the same open-source codebase. There is no separate closed-source edition of the Convertigo platform.

## Key capabilities

- Full-stack web, mobile, PWA and desktop application development
- Pixel-perfect and responsive user interfaces
- Offline-first mobile applications and data synchronization
- REST, SOAP, SQL, NoSQL, ERP, CRM and cloud integrations
- IBM mainframe, IBM 3270, IBM 5250 and AS/400 connectivity and automation
- CI/CD, Git, containers, Kubernetes and on-premises deployment
- LLM connectors and AI-assisted application development
- Model Context Protocol support for coding agents such as Codex, Claude Code and OpenCode
